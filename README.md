4. Как работает калькулятор
Чтобы обойтись без eval, я создал конвейер обработки выражений (всё находится в calculator.py):

    tokenize: разбивает строку на токены, игнорируя лишние пробелы
    _handle_unary: «приклеивает» унарные плюсы и минусы к числам (например, -5), а конструкции вида -(...) преобразует в 0 - (...).
    validate: проверяет грамматику (баланс скобок, отсутствие операторов подряд, наличие операндов)
    to_rpn: переводит выражение в обратную польскую запись (постфиксная запись)
    calculate_rpn: вычисляет результат из RPN с помощью стека

Поддерживаются операторы +, -, *, /, //, %, скобки, унарные знаки, целые и вещественные числа
Пример разбора -2 * -3:

    Токены: ['-2', '*', '-3']
    RPN: ['-2', '-3', '*']
    Стек: -2, -3 -> оператор * -> результат 6.0

Работа с числами (Decimal):
Чтобы избежать проблем плавающей точки (вроде 0.1 + 0.2 = 0.30000000000000004), вычисления проводятся через модуль decimal Константы точности (28 знаков) и режим округления ROUND_HALF_UP заданы прямо в начале файла calculator.py. Итоговый результат округляется до 6 знаков после запятой и возвращается как float
5. Конвертер
Поддерживаемые группы единиц:

    Длина: mm, cm, dm, m, km
    Масса: g, kg
    Температура: c, f, k

Особенности реализации:

    Регистр единиц не важен (можно писать KM, Km или km)
    Конвертация между разными группами (например, кг в метры) будет выдаваться ошибка
    Температура ниже абсолютного нуля (-273.15 °C) блокируется специальной проверкой и выдается ошибка
    Все коэффициенты хранятся в units.json. Файл читается напрямую через стандартный модуль json внутри converter.py. Чтобы добавить новую единицу, достаточно поправить этот JSON, не трогая Python-код

6. История вычислений
Каждое успешное вычисление команды calc дописывается в файл history.json:
[
  {"expression": "2 + 2", "result": 4.0, "timestamp": "2025-01-01T12:00:00"}
]
Если файл вдруг окажется повреждён или будет отсутствовать, программа не упадёт с ошибкой, а просто корректно создаст новый и начнёт вести историю заново
7. Обработка ошибок
Все пользовательские ошибки выводятся в stderr, а программа завершается с кодом возврата 2 (успех = 0). Классы исключений описаны в calculator.py и converter.py:

Пустое выражение
EmptyExpressionError

Недопустимый символ в строке
InvalidCharacterError

Пропущенный операнд
MissingOperandError

Два оператора подряд
ConsecutiveOperatorsError

Деление на ноль
DivisionByZeroError

Несбалансированные скобки
MismatchedParenthesesError

Неизвестная единица измерения
UnknownUnitError

Попытка конвертировать несовместимые единицы
IncompatibleUnitsError

Температура ниже абсолютного нуля
AbsoluteZeroError

8. Тестирование
В проекте написано 39 тестов на pytest, которые покрывают всю основную логику:

    17 тестов калькулятора (позитивные и негативные сценарии).
    7 тестов конвертера (включая проверку на абсолютный ноль и несовместимые единицы)
